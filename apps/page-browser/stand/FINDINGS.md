# Этап 1, стенд: находки по ходу

Рабочие заметки прототипа; итог — в отчёте этапа 1.

1. **Перехват `Fetch` на browser-цели не действует на вкладку, открытую до
   `Fetch.enable`.** Chrome 155: запрос из вкладки `about:blank`, с которой
   Chrome стартовал, ушёл в прокси без `Fetch.requestPaused`. Во вкладке,
   открытой после `Fetch.enable` (`Target.createTarget`), запрос встаёт на
   паузу. Причина — перехват ставится при создании загрузчиков; у
   browser-цели нет обновления уже созданных. Следствие для §4.1 плана:
   рабочая вкладка открывается после включения перехвата, стартовая
   закрывается; восстановление вкладок при запуске запрещено политикой
   (`RestoreOnStartup`), иначе сайт загрузился бы до перехвата.
