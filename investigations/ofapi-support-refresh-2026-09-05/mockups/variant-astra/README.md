# Мокап «Вариант-Астра»

Независимый вариант страницы **Настройки → Сбор данных**, сохранён 05.09.2026.

**Статус: только мокап для сравнения. В план реализации не входит.** Сохранение не утверждает дизайн, набор экранов или продуктовые решения и не означает завершение этапа S-UI.

## Открыть

[Открыть мокап](index.html) — самостоятельный HTML: React, стили и шрифты встроены, сборка и интернет не нужны. Для локального HTTP-просмотра из этой папки:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Данные демонстрационные. Все настройки меняются только в localStorage текущего браузера; нет OFAPI-запросов, списаний или загрузки реальных файлов. Внешний вид и поведение исходного макета сохранены.

## Что сохранено

- `index.html` — готовая переносимая страница.
- `source.zip` — редактируемые React/Vite-исходники, lockfile, инструкции, отчёт проверки и снимки браузера; без node_modules и сгенерированного dist.
- `snapshot.json` — контрольные суммы готового файла, архива и исходного App.jsx.

Исходники можно распаковать отдельно (`unzip source.zip -d source`), затем выполнить `npm ci` и `npm run dev -- --host 127.0.0.1 --port 4173`.

Мокап содержит режимы категорий, бюджеты, паузу, проверку изменений, историю, разовые задачи и мобильную компоновку. Его тексты, числа, цены и ограничения — пример поведения; серверные контракты и реальное включение функций определяются отдельно.
