# Вариант-Астра

Это сохранённый независимый мокап, не утверждённая реализация. Не включать его в нормативный план и не переносить его поведение в production без отдельной задачи владельца. UI реализуется отдельным этапом S-UI. Не менять этот снимок при разработке других вариантов. Редактируемые исходники находятся в source.zip; index.html — переносимая сборка без внешних зависимостей.
