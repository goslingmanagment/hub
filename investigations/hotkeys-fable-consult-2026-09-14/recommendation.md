# Общие хоткеи ChatGoose: результат консультации

Получен ответ Fable 5.1 в сохранённой сессии `a456918d-5478-4bdc-9d8d-879cf1cd8c19`. После независимой проверки двух технических утверждений выполнен дополнительный обмен; оба исправления приняты моделью. Версия модели подтверждена метаданными обоих успешных запусков, подмены модели не было.

## Предлагаемое решение

Добавить в desktop комбинации расширения как дополнительные способы вызвать общие действия. Существующие desktop-комбинации продолжают работать. Переключатель схем не требуется. Для Windows пример: Reply = Ctrl+R или Alt+Shift+E; Improve = Ctrl+I или Alt+Shift+F; Ping = Ctrl+P или Alt+Shift+D. На macOS дополнительные сочетания берутся из расширения с Cmd+Shift.

Начальный общий набор: Reply, Improve, Greeting, Ping, Review, Tone, Cancel. Help, Recap/Scan, Coach, Split и Spenders требуют отдельного сопоставления действия и поведения; одинаковая клавиша не должна обещать отсутствующую функцию.

Перед реализацией проверить Alt+Shift+буква на целевой Windows с включённым переключением RU/EN, в Firefox и desktop, при фокусе в редакторе. Если комбинация меняет язык или теряется, дополнительные сочетания наследуют проблему и требуют другого решения. Живой тест ещё не проведён.

Видимые по исходникам необходимые изменения: desktop должен пропускать новые Alt-комбинации в редактируемых полях; буквенные хоткеи в обоих клиентах должны сохранять работу при RU/EN; справка и подсказки должны отражать оба сочетания. Обработку буквенных комбинаций и обычного ввода/пунктуации следует различать.

Alt+цифры остаётся отдельным кандидатом на улучшение Windows-эргономики, если реальный тест выявит проблему Alt+Shift. Введение нового набора не требуется только ради совпадения текущих клавиш между клиентами.

## Исправления первичного ответа

- Alt+цифра не содержит Shift и не совпадает с сочетанием Alt+Shift для переключения языка. Опциональная цифровая схема также не удаляет старые комбинации, но требует изучить новую карту тем, кто её выбрал.
- Desktop lockfile закрепляет Electron 41.7.2. В исходниках этой версии pasteAndMatchStyle на macOS имеет Cmd+Option+Shift+V, поэтому заявленная гипотеза о конфликте с Cmd+Shift+V не подтверждается: https://raw.githubusercontent.com/electron/electron/v41.7.2/lib/browser/api/menu-item-roles.ts (строки 137–141).
