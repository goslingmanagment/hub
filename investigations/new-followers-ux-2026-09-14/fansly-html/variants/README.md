# Пять вариантов Fansly

Открыть `index.html` в Chrome или через существующий локальный сервер: `http://127.0.0.1:8926/variants/index.html`.

Это интерактивные варианты для выбора, а не интеграция с Fansly. Все данные вымышлены; генерация и отправка имитируются. Каждый вариант имеет независимое состояние. «Начать заново» сбрасывает только выбранный вариант; перезагрузка сбрасывает все.

1. **В списке** — доработка текущего окна: раскрываем переписку и черновик внутри строки. После отправки фан исчезает из очереди.
2. **Чат рядом — выбран пользователем.** Очередь слева, переписка и черновик справа. Открывается по умолчанию. Генерация только по кнопке «Сгенерировать»; открытие окна и выбор фоловера её не запускают. Можно написать вручную. При возвращении к фану сохранённый черновик появляется сразу. После отправки можно прочитать результат и перейти дальше.
3. **По одному** — последовательный проход: профиль, последние сообщения, черновик, «Пропустить» и «Отправить и дальше». Очередь доступна по счётчику.
4. **Готовые тексты** — лента редактируемых приветствий с отдельной отправкой у каждого. Контекст чата раскрывается по желанию. В реальной реализации можно заранее готовить видимые строки и немного следующих, а не генерировать весь диапазон сразу.
5. **Сбоку** — узкая панель с аватарами очереди и мини-чатом. В интеграции она оставляет страницу Fansly доступной. Здесь рядом показано только обозначение страницы, без подключения к реальному аккаунту.

Общее: десять периодов от 1 до 720 часов, начальные 48 часов, время follow всегда в часах, аватары, кастомное имя в скобках, сохранение черновиков при переключении, повторная генерация, явная отправка, защита от двойного клика, сохранение текста при неопределённом результате. Фоловеру, который написал первым, подготовлен ответ по его сообщению.

Основа: существующий `../index.html`, его встроенные шрифты, Feather-иконки, вымышленные аватары и демонстрационные данные. Новые варианты не меняют исходный макет.

Исходники: `layout.html`, `variants.css`, `variants.js`. `python3 build.py` собирает автономный `index.html` со встроенными ресурсами. Результаты проверки — `design-qa.md`.
