# Повторная проверка качества и регрессий

Дата: 2026-09-12. Исходная версия интерфейса: `c0cd21c3`; начало этого прохода: `273469e6`. Проверено рабочее дерево ветки `codex/feature-controls-20260911`. Изменения локальные, без production-записей, deploy, push или merge.

## Результат

Два независимых агента проверили настройки и операции с изменением данных. Координатор дополнительно просмотрел ежедневные страницы, навигацию, формы и итоговые исправления, выполнил тесты и браузерные сценарии. Исправлены три конкретных недостатка; после повторного чтения diff и проверок новых подтверждённых P1/P2 не осталось в проверенном диапазоне. Это не доказательство отсутствия любых ошибок или оптимальности без измерений на реальной нагрузке.

| Недостаток | Исправление и проверка |

Выбор уже активного раздела в select ничего не менял, переход через другой раздел размонтировал форму. | В scoped header добавлена ссылка «Все настройки». ## Читаемость и архитектура

- Сохранены React state, React Router и TanStack Query; новые библиотеки и универсальные автоматы состояний не добавлялись.
- Общее построение settings URL вынесено в небольшой helper вместо двух копий очистки feature-параметров. Оригинальный объект URLSearchParams не изменяется.
- Query options экспортов общие для обычного списка и восстановления. Recovery observer выключен для автоматического чтения, поэтому второго polling timer нет. Точечная отмена не затрагивает GET другой страницы.
- Форматирование улучшено в изменённых блоках. Комментарии объясняют причины сохранения mounted формы, отмены initial GET и различий CSV, а не пересказывают JSX.
- Полный набор строк configuration остаётся mounted для сохранения draft/receipt при фильтрации. Повторное построение небольших Map для карточек не признано проблемой производительности без измерений; speculative memoization не добавлялась.
- Проверены frozen mutation targets, receipt/unknown состояния, stale-data guards и разделение preview/submit. Разные recovery flows не объединялись: серверные гарантии у них различаются.

- Root strictness ratchet: **1897 известных ошибок в 120 файлах**, без увеличения. Это не чистый root `tsc`.
- Дополнительный ESLint с `--no-ignore` на всех **73 изменённых TS/TSX dashboard-файлах** относительно baseline: **0 ошибок, 0 предупреждений**.
- Целевой прогон: **5 файлов, 70 тестов**. Включает настоящие runtime CSV gates/override validator, navigation lifetime, unknown recovery guards и actual QueryClient с отменой initial GET, поздним ответом, cache/error/retry и параллельным чтением другой страницы.

В браузере проверены мобильный возврат с двумя черновиками, CSV `, ,` как все шесть Fansly-страниц плюс будущие, старый cache/неуспешное чтение export jobs, возврат B→A для recovery, сброс acknowledgement при смене страницы и повторном чтении, подготовка без POST.
