## Выкладка

Стандартная команда из этой release-ветки:

```sh
bash scripts/deploy-production.sh --mode dist-only --no-image-gc root@45.8.230.111
```

Скрипт использует обычные release locks, сохранение текущего image/release files для rollback, health gates, проверку dashboard и пересборку production-pinned CLI. Flags/config, replay/recovery, provider subscriptions и image GC в этот релиз не входят. Откат — на снятый текущий production image с сохранением уже применённой схемы. Результат выкладки должен быть записан отдельной проверенной квитанцией; этот документ фиксирует подготовку.
