# Аналитика: что есть и чего нет (обзор для владельца)

Роадмап, «Features on top of the core», п. 7: сначала обзор, потом короткий список на выбор; кода аналитики до выбора

## Что есть

**Дашборд Hub**

- «Обзор»: выручка по моделям и страницам с изменением, раскрытие по видам денег.
- Страница модели: выручка по дням, спендеры, транзакции, подписчики, фолловеры.
- «Топ фанов»: удержание (активные / остывают / неактивные / вернуть), уровни Кит / VIP / Постоянный, «ждёт ответа».
- «Аналитика» и «Статистика» — только Fansly: структура дохода, месяцы, трафик по источникам, доля FYP, медиа и теги,
  собственная статистика Fansly (раз в час).
- «Расходы»: AI по сотрудникам и фоновые прогоны, кредиты OnlyFansAPI против выручки, ссылки OnlyFans.
- «Команда» (Chat Memory): фактические смены, доля сообщений без автора, итоги подходов «Вернуть».

**Telegram из Hub**: утренний отчёт о выручке (net, сутки 02:00–02:00 МСК, 7 и 30 дней) и сводка тревог. О команде — ничего.

**/OS и рутины**: месячные цифры (`month.py`: заработано / пришло / в пути), закрытие месяца, `finance.xlsx`, карточка
смены в «Обучалке» (`shift-audit`: чаты, сообщения, продажи gross, PPV, медиана ответа, ждущие — без деления по чаттерам),
кастомы (`customs-daily`, только Lora и Lilly), трафик (`traffic-daily`), таблицы выплат, отчёты OnlyMonster для
поставщиков трафика (только OnlyFans), разовые аудиты (чаты Lora 25.09, Мирон на Lilly 28.09, реактивация 22.10).

Расхождение: карточка смены считает gross, выплаты и утренний отчёт — net.

## Чего нет (то, о чём просят роадмап и чаты команды)

1. Выручка по чаттеру, когда двое на одной странице в одно время.
2. Восемь чисел на чаттера за смену и неделю, одинаково для Fansly и OnlyFans, включая «руками / Reply / Fix».
3. Конверсия PPV по чаттеру и по цене; цена первого PPV новому фану.
4. Время ответа против покупок (по разовому аудиту: 26,3 % против 7,4 %).
5. Возврат молчунов во времени и по подходам (частично — вкладка «Подходы»).
6. Кастомы: оплата ↔ заказ, «отдали фану», Ari, срок исполнения.
7. Спорные продажи и «долёты», сверка отчётов чаттеров с Hub.
8. Командный блок в утреннем отчёте: ждавшие ночь, открытые кастомы, споры.
9. Часы без чаттера по расписанию и их цена (по аудиту 25.09 — 43 % пустых часов).
10. Воронка приветствий: доля поприветствованных, ответы в первый час.
11. Отвечают ли на рассылки.
