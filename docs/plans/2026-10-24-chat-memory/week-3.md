## Что уже есть

- **«Ждут ответа».** `clientSpenderAwaitingReply` (`packages/db/src/repositories/spender-stats.ts`): только платившие,
  фан ждёт, если его последнее сообщение новее последнего сообщения страницы; порядок — по тратам, потом по
  ожиданию. Беда: **рассылка считается ответом** — `last_model_message_at` берёт любое сообщение страницы, а на
  lora-1 за неделю 3972 из 6382 исходящих — рассылки. Правило «личного исходящего» уже есть
  (`message-authorship.ts`, неделя 1), здесь не используется. В строке нет `conversationRef` (группы Fansly).
- **Молчуны.** Счётчики тишины (8–21 и 21+ дней по последнему тексту фана) без списка; в расширении — свои фишки
  по любому сообщению. Порога 14 дней нет. `retentionStatus` на `/spenders` — по покупкам, расширение не читает.
- **Подписки.** Даты конца и автопродление — в `page_subscriptions` / `page_fans` (Fansly — раз в час и по сокету,
  OnlyFans — раз в сутки); готовый запрос `listSubscribersForPage(expiringWithinDays, autoRenew)`, расширению закрыт.
- **Новые подписчики.** `clientAudienceNew` — только OnlyFans, с `lastPersonalSendAt` из авторов недели 1; на
  Fansly «Новые» — собственный проход расширения по фолловерам.
- **Попытки и их итог** не записываются нигде: `follower_outreach_attempts` — старый замок приветствий без итога.
  Есть из чего считать: авторы сообщений (`client_send_attributions`), архив, транзакции, «в разговоре», смены.
- **Расширение.** Окно «Спендеры» — модальное и закрывается при открытии чата: живым списком на смену оно быть не
  может. Боковая панель фана живёт при смене чатов; опрос раз в 30–60 с — у «Новых» (`domain/newcomers/poll.ts`).

## 1. «Ждут»

- Фан ждёт, если его последнее сообщение новее последнего **личного** исходящего страницы (не рассылка Fansly
  `message_type = 2`, не пачка одного текста на ≥ 5 чатов за час) — то же правило, что у доли без автора.
- Все фаны, не только платившие: сначала по тратам, потом по времени ожидания. В строке — сколько ждёт, сколько
  потратил, `conversationRef`, «в разговоре» (кто), отметка из псевдонима (💵/❌).
- Хаб: тот же маршрут `clientSpenderAwaitingReply` с новым правилом ответа и полями (дополнения, старый клиент не
  ломается), плюс включение неплативших параметром.

## 2. «Вернуть»

- Новый маршрут `clientWinBack` (страница в пути, только база): объединение трёх причин, у строки — причина:
  - платил и молчит ≥ 14 дней (последний текст фана);
  - подписка кончается в ближайшие 3 дня без автопродления;
  - новый подписчик за 7 дней, которому никто не написал лично (по авторам недели 1; на Fansly — по подпискам
    `page_subscriptions`, которые хаб уже собирает).
- Убираются фаны «в разговоре» и те, кому за последние 7 дней уже был подход. По тратам, не больше 10 на страницу
  за раз — чтобы не вытеснять тех, кто ждёт.

## 3. Подходы и итог

- **Подходы** — список владельца (таблица, правка на `/team`): на старте «Деталь из памяти», «Бесплатное фото»,
  «Мягкий PPV». Владелец меняет список по итогам.
- **Попытка**: чаттер в строке «Вернуть» одним касанием выбирает подход и пишет сам. Хаб журналит выбор в
  `observations` (как факт «кто отправил»), пишет попытку (страница, фан, кто, подход, причина, когда) и
  привязывает первое сообщение этого чаттера фану после выбора (по авторам недели 1).
- **Итог** считается при чтении, без воркера: ответил за 72 часа (сообщение фана в архиве), купил за 7 дней
  (транзакция с суммой > 0), потратил за 30 дней. На `/team` — вкладка «Подходы»: по подходу и по чаттеру.
- Хаб подход не назначает и продажу никому не засчитывает: только записывает и считает (роадмап, «Not doing»).

## 4. Передача смены

- Маршрут `clientHandoff` для страницы: кто сейчас «в разговоре» и с кем говорил уходящий чаттер за свою смену,
  кто ждёт, открытые обещания (факты недели 2, вид `promise`). Кастомы — с недели 4; до неё — «не знаю».
- В расширении — вкладка «Передача» той же панели, видна в начале смены.

## 5. Расширение: панель «Очередь»

- Боковая панель с вкладками «Ждут» / «Вернуть» / «Передача», живёт при смене чатов (не модальное окно),
  опрос раз в 30–60 с по образцу «Новых». Строка открывает чат, не закрывая панель; на строке — «в разговоре: имя».
- В «Вернуть» — фишки подходов в один касание и пометка «подход выбран».
